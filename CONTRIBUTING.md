# Contributing to CLogic Dialogue System

Thank you for your interest in contributing to the CLogic Dialogue System.

Contributions may include bug fixes, new features, documentation improvements, examples, tests, and other improvements to the project.

## Before Contributing

Before making a substantial change, consider opening an issue first to discuss the proposed change. This helps avoid duplicated work and ensures that the change fits the direction and architecture of the project.

## Pull Requests

When submitting a pull request:

- Target the `dev`.
- PRs should contain single change or closely related set of changes.
- Clearly describe what the change does and why it is needed.
- Document any breaking changes or changes to public APIs.
- Follow the existing code style and architecture of the project.
- Test your changes before submitting them.

A contribution may be modified, declined, or removed at the discretion of the maintainers.

## Issues and Bug Reports

When reporting a bug, include enough information to reproduce the problem where reasonably possible, including:

- the Unity version
- the Dialogue System version or commit
- steps to reproduce the issue
- expected behavior
- actual behavior
- relevant errors, logs, screenshots, or minimal reproduction examples.

Please remove credentials, license keys, personal information, and other sensitive information before posting logs or project files.
